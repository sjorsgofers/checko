# Karateschool Yin Yang — website

Statische website van Stichting Karateschool Yin Yang (Kyokushin karate, Eindhoven & Budel).
Een moderne herbouw van www.kyokusyinyang.nl met dezelfde inhoud.

## Structuur

| Bestand | Pagina |
|---|---|
| `index.html` | Home |
| `yin-yang.html` | Geschiedenis van de school |
| `kyokushin.html` | Kyokushin & disciplines |
| `kata.html` | Kata |
| `coaches.html` | Coachteam |
| `kader.html` | Kader & sportschoolhouders |
| `junior-lessen.html`, `senior-lessen.html` | Lessen en trainingstijden |
| `speciale-trainingen.html` | Themalessen, bondstrainingen |
| `zelfverdediging.html`, `cursus-pakketten.html` | Only Lady's |
| `iedereen-doet-mee.html` | Leergeld & Volwassenenfonds |
| `wedstrijdteam.html`, `behaalde-prestaties.html` | Wedstrijdteam |
| `sponsors.html` | Sponsors & Open NK 1 november 2026 |
| `proefles.html`, `inschrijven.html` | Formulieren (openen een e-mail naar kyokusyinyang@gmail.com) |

`assets/` bevat de stylesheet, het script (menu, scroll-animaties, tellers, aftelklok ONK), het Yin Yang-logo en het Kanku-symbool.
`archief/` bevat de eerdere inhoud van deze repository.

## Foto's

De foto's van de oude site konden niet automatisch worden overgenomen. Plaats ze in een map `images/` en voeg ze toe waar gewenst.

## Lokaal bekijken

Open `index.html` in een browser; er is geen build-stap nodig.
